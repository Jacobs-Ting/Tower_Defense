# 鋼鐵防線：1944（Steel Defense: 1944）

二戰諾曼第背景的 HTML5 俯視角塔防遊戲。純 HTML5 / CSS3 / JavaScript（Canvas 2D），無外部依賴、無音檔、無圖檔。

## 如何遊玩

- **本機：** 直接雙擊 `index.html` 即可（使用傳統 `<script>` 載入，沒有 ES Module 的 `file://` 限制）。
- **GitHub Pages：** 把整個資料夾推到 repo，在 Settings → Pages 選擇分支即可。所有資源都用相對路徑。

## 操作

| 動作 | 方式 |
|---|---|
| 選擇武器 | 點左側卡片或按 `1`–`6` |
| 建造 | 點綠色部署格（按住 `Shift` 可連續部署） |
| 取消 | 右鍵 / `Esc` |
| 選取陣地 | 點擊已建造的陣地 → 右側面板升級／拆除／修復 |
| 升級 / 拆除 / 修復 | `U` / `X` / `R` |
| 開始下一波 | `N` 或下方按鈕（倒數期間提前開波可得補給：剩餘秒數 × 2） |
| 暫停 / 速度 | `空白鍵` / `F`（1× ↔ 2×） |

暫停期間仍可部署、升級、拆除。

## 內容

**武器（6 種）：** M1919 機槍、M2 60mm 迫擊砲（第 3 波）、M1 57mm 反戰車砲（第 5 波）、Bofors 40mm 防空砲（第 7 波）、M2A1 105mm 榴彈砲（第 8 波）、QF 17-pounder（第 9 波）。各有 3 個等級，升級內容皆為二戰時期可行的改良（裝填效率、沙包、前進觀測、M86 APC、APDS、Kerrison 射擊指揮儀）。

**敵軍（7 種）：** 步兵、MG42 機槍班（壓制附近陣地射速）、Sd.Kfz. 251、Panzer IV、Panther、Tiger I（第十波 Boss）、Ju 87（沿獨立航線、3.2 秒預警、轟炸指揮部或陣地）。

**系統：** 傷害類型 × 裝甲類型倍率表（依任務書）、「穿甲命中／跳彈／無法穿甲／裝甲抵擋／擊落」浮動提示、範圍爆炸（同次爆炸對同一敵軍只算一次）、陣地耐久與空襲失能、準備階段修復、拆除退 50%、提前開波獎勵。

**技術：** `requestAnimationFrame` + 固定步長（1/60 秒）累加 deltaTime；2× 速度是每幀執行兩倍步數，所以傷害與生成計時跟 1× 完全一致。

## 測試結果

`node tests/headless_test.js` — 23 項單元測試全部通過，外加用自動指揮官跑 5 個亂數種子的十波模擬：

| 情境 | 結果 |
|---|---|
| 完整武器 | 5/5 勝，指揮部剩 3–7 |
| 只用 57mm（無 17 磅砲與 105mm） | 5/5 勝，指揮部剩 3–9 |
| 不建防空砲 | 1/5 勝（空襲是真正的威脅） |
| 只用機槍 | 0/5，第 6 波失守 |

在 Chrome 中實際跑完十波到勝利畫面，Console 沒有錯誤；點擊建造、縮放後的座標換算、暫停、重新開始也都測過。

## 仍需改善

- 平衡只用自動指揮官調過，真人遊玩後可能還要微調（全部集中在 `js/config.js`）。
- 索敵只做了「最前方」；最近、最強、最弱只預留了架構，沒有實作。
- 目前只有一張地圖；歷史圖鑑、戰役模式要等之後的版本。
- 沒做行動裝置觸控最佳化，以桌面瀏覽器為主。
- Ju 87 在 1944 年諾曼第並不是典型的大規模空襲機型，這一關是架空設定，之後可以換成 Fw 190 對地攻擊型。
